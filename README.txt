Keep all files in the same folder. The page loads the images by
file name, so renaming or moving one breaks that image.

TO VIEW IT
  Double-click index.html. It opens in any browser. Fonts need internet; offline it falls back to system fonts.

TO PUT IT ONLINE, FREE
  Netlify Drop   app.netlify.com/drop
    Drag this whole folder onto the page. You get a live link in
    seconds. No account needed to start.

  GitHub Pages
    Create a repository, upload these files, then
    Settings > Pages > Branch: main > Save.

  Vercel         vercel.com/new
    Import the folder or a GitHub repository.

All three give you a free address. You can connect your own
domain later in the same settings.

TO EDIT IT
  Open index.html in any text editor (Notepad, VS Code).
  Your text is near the bottom of the file, in plain HTML.
  The colours and fonts are at the top, in the :root block.

BEFORE SHARING
  The Dubai drawings say they are the consultant's property and
  must not be used without their authority. The title block is
  redacted, but get their permission before the link is public.
